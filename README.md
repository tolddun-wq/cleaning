# «Чистовик» — демо-сайт клининга

Демо-проект для портфолио. Компания вымышленная: звонок и подтверждение заказа показывают плашку «Это пробный сайт» со ссылкой на Telegram @isthisthedaggr.

Идея: сайт — это наряд-заказ на уборку. Посетитель сам заполняет бланк, корешок сразу считает цену, на обороте собирается чек-лист с составом каждого средства.

## Страницы

- `index.html` — главная: бланк с калькулятором, гарантии, чек-лист, состав средств, фото, день уборки, отметки-примеры
- `order.html` — оформление в 4 шага: расчёт, время, данные, проверка
- `usloviya.html` — условия и договор
- `404.html` — «Такого пункта в наряде нет»

## Устройство

Статический сайт без сборки: HTML, CSS, JavaScript.

- `js/data.js` — тарифы, допы, состав средств
- `js/engine.js` — расчёт цены, времени и бригады
- `js/blank.js` — бланк, корешок, чек-лист
- `js/order.js` — шаги заказа
- `js/ui.js` — плашка пробного сайта и меню

Бланк хранится в браузере (localStorage), никуда не отправляется.

Шрифты: IBM Plex Sans Condensed, Onest, Martian Mono, Bad Script (Google Fonts, SIL OFL). Фото: Unsplash, список в `photos.txt`.

## Хостинг

Vercel, тип проекта Other, без настроек. Любой статический хостинг тоже подойдёт.
